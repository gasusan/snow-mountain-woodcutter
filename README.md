# 雪山の丸太割りゲーム

## 起動方法（Windows）
1. ZIPを解凍する
2. 解凍したフォルダを開き、PowerShellでそのフォルダへ移動する
3. `npm.cmd install` を実行
4. `npm.cmd start` を実行
5. ブラウザで http://localhost:3000 を開く

## セーブ
ゲームデータはブラウザ内（localStorage）に自動保存されます。同じブラウザで遊んでください。

## 主な要素
- クリック／長押しで丸太割り、クリティカル、コンボ
- レベル・経験値・スキルポイント
- 斧・腕力・技術・集中力・自動作業員の強化
- 8種類の木材と段階的な木材解放
- 薪の販売、依頼、実績、デイリー報酬
- 雪山探索、ランダムイベント、天候ボーナス
- ペット、作業小屋、転生（山の伝説）
- オフライン経過報酬、セーブ／ロード用コード
