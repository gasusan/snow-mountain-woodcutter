# 雪山の丸太割り v2.0

## 起動方法
1. Node.js をインストール
2. このフォルダで `npm install`
3. `npm start`
4. ブラウザで `http://localhost:3000` を開く

## v2.0 の追加内容
- ペット6種類。コインで仲間にし、個別にコインでレベルアップ（最大Lv.50）
- ペットが作業場の背景に登場して動く
- 山の星スキルツリーと転生報酬の改善
- 自動作業を累積処理に変更し、高レベルで効率が頭打ちにならないよう調整
- クリティカル率・各倍率の表示、実績マイルストーン報酬
- BGM音量スライダー（0〜100、設定保存）
- 天候に応じた背景変化、丸太の大型化・木材ごとの色変化、斧の振りアニメーション
- 既存の `snowWoodSave` を読み込み、追加項目は初回起動時に補完

## セーブ・アカウントについて
v2.0 は既存どおりブラウザの localStorage に保存します。Render の無料Webサービスでは永続ディスクやDBを別途用意しない限り、サーバー側のアカウント・クラウドセーブ・ランキングを安全に保証できません。そのため、ログイン画面やランキングを見せかけで追加していません。アカウント・共有ランキングは PostgreSQL 等の永続DBを設定してから次段階で実装する必要があります。
